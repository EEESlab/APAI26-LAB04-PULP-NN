# Helloworld from PULP

Open a new terminal in VS Code, inside the Docker container (personal machines), or a terminal inside the virtual machine after running `source setup_pulp_sdk.sh` (lab machines). See the [main README](../README.md#quickstart) for details.

Run the helloworld:
~~~~~shell
cd 00_pulp_hello_world
make clean all run
~~~~~

You should see _Hello, world! -from PULP_ in your terminal! :)
